# 私人营养师系统 —— 测试文档（精简版）

**版本**：v1.1  
**测试范围**：核心功能 + AI效果 + 社交功能  
**测试原则**：简单验证，能跑通即可，不做复杂性能测试

---

## 一、测试策略

| 类型 | 方法 | 负责人 |
|------|------|--------|
| 接口测试 | Postman/Apifox | A、C |
| 功能测试 | 手动点击 | 全员 |
| AI效果测试 | 固定样本验证 | C、D |
| 前后端联调 | 浏览器实测 | B |

**原则**：不写复杂自动化测试，重点验证“能不能用”。

---

## 二、测试环境

| 项 | 说明 |
|----|------|
| 后端 | 本地 SpringBoot + FastAPI |
| 数据库 | MySQL 8.0 |
| 前端 | Chrome 浏览器 |

| 工具 | Postman、浏览器 |

## 四、AI效果测试

### 4.1 识别准确率（C负责）

**方法**：准备 10 张常见食物图片，人工核对识别结果。

| 图片 | 期望 | 实际 | 是否准确 |
|------|------|------|---------|
| 米饭 | 米饭 | | |
| 牛肉面 | 牛肉面 | | |
| 鸡蛋 | 鸡蛋 | | |
| 沙拉 | 沙拉 | | |
| 汉堡 | 汉堡 | | |
| 炒饭 | 炒饭 | | |
| 苹果 | 苹果 | | |
| 牛奶 | 牛奶 | | |
| 鸡胸肉 | 鸡胸肉 | | |
| 多菜混合 | 多个食物 | | |

**标准**：10 张中至少 7 张识别正确即通过。

### 4.2 建议合理性（D负责）

**方法**：构造 3 种场景，人工判断建议是否合理。

| 场景 | 输入 | 期望 | 是否合理 |
|------|------|------|---------|
| 减脂缺口 | 热量缺口 600 | 建议低热量高蛋白 | |
| 增肌缺口 | 蛋白质缺口 50g | 建议高蛋白食物 | |
| 过敏冲突 | 过敏花生 | 不推荐花生 | |

**标准**：3 个场景均合理即通过。
